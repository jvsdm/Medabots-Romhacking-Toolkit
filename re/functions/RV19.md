# RV19: revisao de nomes (60 enderecos de RV19_lista.txt)

Detalhes por endereco em `RV19_simbolos.csv`. Aqui so trocas de nome e achados.

## Trocas de nome (renomeadas no Ghidra)
- 0x080593FA: `Screen_NoopReturn` -> `Screen_ReturnEpilogue`. Nao e noop: e epilogo (`add sp,4; pop {r4,r5}; pop {r0}; bx r0`), usado como retorno no default de `Screen_RedrawAndDispatchStep`.
- 0x0805BBE0: `MainState2` -> `MainState_Dispatch2`. Despacha subestado pela tabela.
- 0x08068440: `MainState3` -> `MainState_Dispatch3`. Mesmo padrao, estado inicial do boot.
- 0x08065D44: `LinkMenu14Step0` -> `LinkMenu14_InitScreen`.
- 0x080665B0: `LinkMenu14Step6` -> `LinkMenu14_WaitThenSetPreviewScene`.
- 0x0806668C: `LinkMenu14Step9` -> `LinkMenu14_DispatchIndexCountOrSkip`.
- 0x080666F4: `LinkMenu14Step11` -> `LinkMenu14_DispatchIndexCountReset`.

## Achados
- O prefixo `LinkMenu14` vem do numero do estado; o nome "LinkMenu" ainda nao foi confirmado pela tela.
- `Battle_SetDefaultsA/B/C/D` gravam (2, valor, 0) com valores diferentes; sufixos sem significado ainda.
- `Site_RunSaveLoadOption` (0x0805DDEC) usa prefixo `Site_`, fora da convencao `Save_`; mantido, a decidir.
- `SaveLoad_SaveGame` (0x0805E010) ja traz comentario com o layout do save (assinatura, RAM 0x03002B70, 0x03000BE0, 0x03004C40, 0x030057E0, checksum em 0xFF4). Vale conferir com o mapa de RV19 antes de reusar.
- `Screen_ReadTwoBitField` (0x0805BB0C) copia 4 bytes de rascunho sem efeito; so o campo de 2 bits importa.
- Varias funcoes tem jumptable nao recuperada (`Could not recover jumptable`); os nomes deles vem do despacho, nao da tabela.
