# R4 — funções da ROM, faixa 4 (GH-R4)

Formato: ver README.md. Endereços da ROM EU (Metabee). Nomes Ghidra FUN_ quando não renomeados.

## 0x08067314 bg_fill_row_tiles
- Assinatura: `void bg_fill_row_tiles(int n, int col)`
- O que faz: monta 32 halfwords num buffer local (CPUFastSet) e, se `col<14`, preenche `n` células com um tile fixo (`*DAT_08067370`), escolhendo tile vazio/cheio (DAT_080673a0/a4). Copia o buffer para o tilemap do BG (base = `(reg>>8 &0x1f)*0x800`) com CPUFastSet de 16 words.
- Chama: CPUFastSet (0807CCC0), 0807CD2C (divisao com sinal, aux_div_s32). Chamada por: UI de menu/texto (provável).
- Memória: escreve VRAM tilemap (0x06000000+); lê ROM (DAT_0806736c..) e RAM de DAT_080673a4.
- Para o Lua: porta a lógica de linha de tiles (sem CPUFastSet); o tilemap pode ser ignorado se a UI for redesenhada.
- Confiança: provável.

## 0x080673AC hud_draw_row_tiles
- Assinatura: `void hud_draw_row_tiles(int linha, int modo)`
- O que faz: se `modo<15`, copia 20 bytes (buffer de pilha) para uma linha do tilemap com CPUSet, deslocada por `uVar5` (valor lido de RAM via ponteiros DAT_0806741c/DAT_08067418). Senão, monta 20 halfwords com o tile de destaque (`|0x800`, palette bit) e copia para a linha.
- Chama: CPUFastSet (0807CCC0), CPUSet (0807CCC4). Chamada por: rotinas de tela (provável).
- Memória: lê RAM dos ponteiros DAT_0806741c; escreve VRAM 0x06000100+ (tilemap).
- Para o Lua: "não precisa" (só tilemap); a lógica de destaque (bit 0x800) vira cor/desenho.
- Confiança: provável.

## 0x080674BC draw_text_rtl_tiles
- Assinatura: `void draw_text_rtl_tiles(const char *s, u8 linha)`
- O que faz: mede o comprimento de `s`, percorre do fim para o começo; cada char `c` vira tile `tabela[(c-0x41)]` (fonte só maiúscula, `c-0x41` em halfwords). Para ao achar espaço (0x20) e completa com 0. Escreve até 20 células na linha `linha` do tilemap (base `DAT_0806750c`).
- Chama: — . Chamada por: desenho de textos de tela (provável).
- Memória: lê string (ponteiro de chamada) e tabela de fonte na ROM (DAT_08067510); escreve VRAM tilemap.
- Para o Lua: porta a regra de mapeamento char→tile; o layout é da fonte de tela, não do texto (text.lua já cobre o conteúdo).
- Confiança: provável (mapa de caracteres ainda não conferido contra a fonte).

## 0x08067C04 fx_particles_blend_step
- Assinatura: `void fx_particles_blend_step(void)`
- O que faz: percorre 16 registros de 0x40 bytes (base RAM DAT_08067c58). Se o contador (+0x34) é 0, reinicia (x=0x78, y=0x28, dois valores aleatórios via 080424B8 em +0x18/+0x20, contador=0x3F). Senão decrementa, atualiza posições por velocidade (`>>8 + vel*4`) e alfa. Depois fixa BLDCNT=0x0C40, BLDALPHA a partir de um contador global (-1 por quadro) e BLDY=8.
- Chama: 080424B8 (aleatório). Chamada por: cena com efeito de transparência (provável).
- Memória: RAM (registros 0x40 bytes, DAT_08067c58, DAT_08067cf8); IO: REG_BLDCNT (0x04000050), REG_BLDALPHA (0x04000052), REG_BLDY (0x04000054).
- Para o Lua: porta como sistema de partículas com fade (posição/alfa/ttl); os registros de blend viram alfa de sprite.
- Confiança: provável.

## 0x08068888 fx_step_table_a

- Chama: CallViaR0 (0807CCF0) + handlers da tabela. Chamada por: loop de efeito (provável).

- Para o Lua: porta como máquina de estados com handler-por-estado; a tabela de handlers precisa ser lida (ponto de atenção: tabela em ROM DAT_080688bc).
- Confiança: provável.

## 0x08068CC8 fx_palette_fade_step
- Assinatura: `int fx_palette_fade_step(void)` (1 = acabou)
- O que faz: compara progresso `t` (de 0 a N*0x20, em 1/32) com o total; se faltar, calcula para cada cor 15-bit: `(a*(32-t)+b*t)>>5` por canal (5 bits R, G, B) entre a paleta origem e destino; grava no buffer e copia para a paleta BG (0x05000000) por DMA.
- Chama: 0807CDF8, 0807CD2C (aux de mod/div). Chamada por: 0x08068684 (modo 4) e 0x08068888/88E0 (provável).
- Memória: RAM DAT_08068db8 (buffer), DAT_08068dbc (origem), DAT_08068dc0 (destino), DAT_08068dc8; IO: DMA3 e paleta 0x05000000.
- Para o Lua: "não precisa" o DMA; a interpolação RGB555 (`(a*(32-t)+b*t)>>5`) é a regra a portar.
- Confiança: provável (aritmética conferida no decompile; semântica de origem/destino é hipótese).
